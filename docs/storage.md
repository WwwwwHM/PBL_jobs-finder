# 文件存储、访问与保留

## 生命周期

| 数据 | 存放位置 | 保留与删除 |
| --- | --- | --- |
| 浏览器上传的 PDF / 照片 | Gradio 临时缓存 | `delete_cache=(3600, 86400)`：每小时清理超过 24 小时的本实例缓存，正常关闭时由 Gradio 清理；强制终止残留缓存由运维清理独立 `GRADIO_TEMP_DIR` |
| 应用解析副本 | `UPLOADS_DIR` | UUID PDF；`staged_pdf` 在解析完成或失败时删除；进程崩溃残留每小时清理超过 24 小时的受管文件 |
| PDF / Word 导出 | `EXPORTS_DIR` | `{记录编号}-{UUID}.pdf/docx`；每次生成新文件，渲染或数据库提交失败只删除本次文件；下载有效期 24 小时，启动后及每小时清理到期文件 |
| 照片 | 上传缓存、SQLite `photo_data_uri` | 校验图片格式、大小和像素；转为安全图片数据保存于所属简历记录，不单独提供照片下载 |
| 原始文本、优化稿、问答、报告 | SQLite | 清理上传或导出不删除历史。页面“重新开始”和退出只清空页面，不删除业务历史 |
| 旧版本导出、未知文件、备份 | 原有目录 | 自动清理仅匹配本版受管文件名，不递归、不跟随链接、不清理备份。旧文件需要管理员确认后清理 |

当前没有用户自助永久删除历史或自动删除备份的功能。账户/记录删除须通过经授权的数据维护完成，同时处理其关联导出、照片及备份保留策略。退出登录会撤销 Token，已下载到用户设备的文件不受服务器控制。

## 上传校验与失败处理

PDF 依次检查文件存在、非符号链接、`.pdf` 后缀、非空、最大 12 MB、`%PDF-` 文件头；复制过程中再次限额并校验副本。解析拒绝加密、损坏、超过 100 页的 PDF；扫描件 OCR 最多 5 页，失败可粘贴文本。存储键仅接受 32 位十六进制 UUID，拒绝绝对路径及 `..`。

照片最大 5 MB，内容必须为 JPEG/PNG/WebP，并检查像素上限。重新编码去除原始元数据；照片不是任意 HTML 或外部资源 URL。联系方式、照片恢复和技能选择有独立回归测试。

上传副本在调用 AI 前即清理。AI 或数据库失败不会留下不完整诊断；配额退还规则见稳定性文档。PDF 使用临时文件渲染再替换到本次独立文件名，Word 写入失败清理本次文件。数据库更新失败保留上一份成功导出和历史内容。

## 下载权限

请使用 `python frontend.py` 或 `python -m uvicorn pbl_jobs_finder.server:create_app --factory --host 127.0.0.1 --port 7860 --workers 1`。两者均启动包含安全边界的 FastAPI + Gradio 应用；不要单独调用 `build_app().launch()` 绕开该入口。

前端仅返回 `/api/downloads/{key}` 链接，不把导出路径交给 Gradio 缓存。浏览器登录后将有效 Token 通过 `POST /api/session` 同步为 HttpOnly、SameSite=Strict Cookie；HTTPS 下带 Secure 标记。下载每次重新验证 Token 和记录归属，退出撤销立即生效。也可使用 `Authorization: Bearer <token>` 下载；不把 Token 放进 URL。

`/file=...`、`/file/...`、`/stream/...` 拒绝所有通用文件下载，防止绕过记录权限。下载响应为附件并含 `Cache-Control: no-store`、`X-Content-Type-Options: nosniff`。无身份返回 401、其他用户返回 403、非法或到期文件返回 404。Gradio 上传协议仍包含内部缓存路径，这是框架协议字段，不代表该路径可公开下载；不要把服务器路径当作授权凭据。

## OSS / MinIO 适配

`FileStorage` 的 `save_pdf(source) -> key`、`materialize(key) -> context manager[Path]`、`delete(key)` 隔离解析器与物理存储。替换实现应：

1. 上传前沿用校验，生成随机对象键，配置私有 bucket、服务端加密和最小权限凭据。
2. `materialize` 下载至隔离临时目录，限制下载字节数并复查文件头，退出上下文删除本地副本。
3. `delete` 幂等删除对象；提供生命周期规则回收崩溃留下的暂存对象，明确服务失败的补偿和告警。
4. 下载继续通过服务端校验用户及记录归属，再代理文件流。若改为短时签名 URL，需明确链接转发及撤销延迟；对象随机名和私有 bucket 都不能替代归属校验。
5. 导出迁移需要额外的记录—对象键映射及过期字段，不能直接套用当前本地文件名路由；做双读迁移、校验字节摘要和恢复演练后切换。

本阶段未连接真实 OSS / MinIO。SQLite 与文件的一致性恢复、备份期限自动化属于后续交付范围。
